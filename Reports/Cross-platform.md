# 跨平台验证

| 项目 | 验证环境与结果 |
| --- | --- |
| Mac 回归 | macOS 27.2，挂载 APFS 与 exFAT 测试镜像。覆盖快速跳过、移动、版本、断开恢复及源目录消失。 |
| v1 升级 | 验证旧版提交的原始字节保持一致，历史可读，升级后继续提交。 |
| C++ 引擎 | macOS 的 APFS 与 exFAT 测试卷。验证单块增量、同大小修改、无变化零正文 I/O、四个事务中断点、历史清理中断及接管冲突。 |
| Swift → C++ → Swift | 两端实际生成和读取准备记录。Mac 侧使用挂载的 exFAT 测试卷，C++ 侧在 macOS 上运行。两次回滚、历史读取和接管均通过。 |
| Windows x64、ARM64 | Win32 核心已交叉编译为两种架构的 COFF 目标文件。GitHub Actions 配置了 MSBuild、NTFS 和 exFAT 卷测试、Windows 11 启动及辅助功能树检查。完整 WinUI 工程尚未在 Windows 编译或运行。 |
| Windows 11 26H2 和 USB 实机 | 待在对应系统和外置盘上核对深色、高对比度、缩放、键盘、暂停与安全推出。 |

Windows 的性能工作负载为 10 万个 1 KiB 小文件和一个 32 MiB 文件。首次、无变化、修改 1%、批量移动和单块更新分别记录扫描耗时、实际读取量、最新副本写入和历史写入。在 Actions 手动启用 benchmark 或构建预览标签时生成 JSON。

Mac 的实测基线见 [性能报告](Performance.md)。虚拟卷与实机的耗时分别报告。
